# Mecwintech - Employee Management System

Mecwintech is a backend employee management system built using the PHP MVC framework. It streamlines HR processes by offering features for managing employee records, tracking attendance with punch in/out, and generating payslips.

## Features

- **Employee Management**: Create, update, and manage detailed employee profiles.
- **Attendance Tracking**: Log punch in/out times for accurate attendance records.
- **Payslip Generation**: Generate payslips based on attendance and salary data.
- **MVC Architecture**: Organized codebase for scalability and maintainability.
- **File Uploads**: Store employee-related files (e.g., photos) in `public/uploads/`.

## Prerequisites

- PHP >= 7.4
- MySQL or MariaDB
- Apache (e.g., via XAMPP)
- Composer
- Git
